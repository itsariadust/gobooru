# goboorulib

This is a library for connecting with booru-style imageboards written in Go.

This currently supports the following boorus:

- gelbooru

I plan on making these later on:

- danbooru
- safebooru
- rule34
- konachan
- yande.re
- sankaku complex (maybe, they kind of enshittified themselves)

Eventually, you can add your own custom boorus too. I just need to figure out a way to distinguish between Gelbooru-based boorus, Danbooru-based boorus, maybe Moebooru ones too.

I don't plan on adding support for anything pre-0.2 of Gelbooru.
